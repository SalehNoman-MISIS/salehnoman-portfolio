# Screenshots

Put generated project screenshots and diagrams here, one folder per project slug:

```
screenshots/
├── ats-detection-system/
├── ai-job-scraping-platform/
├── data-enrichment-platform/
├── browser-automation-agents/
├── backlink-price-aggregator/
├── gender-prediction-model/
├── google-maps-scraper/
└── tutoring-website/
```

Guidance:
- 2–5 images per project. Prefer real UI captures; for CLI/library/thesis
  projects use terminal captures, plotted results, or clean architecture diagrams.
- Use consistent aspect ratios (e.g., 16:10) and compress (WebP/optimized PNG).
- Name files descriptively, e.g. `dashboard.png`, `agent-log.png`,
  `architecture.svg`, `shap-importance.png`.
- See `../../repos.md` for exactly what to capture per project.
